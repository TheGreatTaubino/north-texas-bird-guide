## Decisions
- Sighting history is local-only in `localStorage` under `northTexasBirdGuide.sightings.v1`
- GitHub Gist sync is optional and opt-in; token is stored locally, never logged or sent elsewhere
- Sighting unit is one species per local calendar date; toggling removes it
- Sightings merge on import — no data is overwritten by a pull or file restore
- No new runtime dependencies added; date handling uses native JS `Date`; GitHub sync uses native `fetch`
- Frequent Flier list is curated manually via `frequentFlier: true` in `birds.js` — not computed from sighting history; current 12: American Crow, Blue Jay, Northern Cardinal, Northern Mockingbird, Mallard, Great Blue Heron, Canada Goose, Great-tailed Grackle, House Sparrow, Mourning Dove, Turkey Vulture, Mississippi Kite
- Windows `*:Zone.Identifier` sidecar files are in `.gitignore`

## Commands
- `npm run dev` — start Vite dev server (add `-- --host 0.0.0.0` to expose on LAN/Android)
- `npm run build` — production single-file build to `dist/index.html`
- `npm run embed-images` — regenerate `src/imageData.js` from `src/images/*.jpg`
- `npm run build:full` — embed images then build
- `npm test` — run vitest unit tests (24 tests, no browser required)
