# Agent Handoff

## Goal
Continue the North Texas Bird Field Guide React/Vite project. The core feature set is complete. Future work is incremental — new species, photo improvements, UX tweaks, or sync enhancements.

## Current State
`feat/google-play` branch is up to date with origin. Working tree is clean.

### Recent Changes
- **Capacitor Android project scaffolded:** `android/` directory contains a Capacitor-generated Android project (`com.alexataube.ntxbirdguide`). Not actively being published — kept in repo for future use.
- **`build:android` script added:** `npm run build:android` runs embed-images + vite build + `cap sync android` in one step.
- **`store-listing/` added:** Contains Play Store listing copy (`play-store-listing.md`) and a hosted-ready privacy policy (`privacy-policy.html`) — kept for reference.
- **`.codex/` excluded from git** via `.gitignore`.
- **OneDrive copy on build:** `npm run build` copies `dist/index.html` to `/mnt/c/Users/alexa/OneDrive/north-texas-bird-guide.html` after every build.
- **Collapsible sightings calendar:** The "Calendar Tracker" heading is a clickable toggle. State lives in `App.jsx` as `sightingsCollapsed`.
- **Search/filters moved below calendar:** `FilterBar` renders after the sightings section.
- **Gist ID persistence:** Gist ID in `localStorage` (`northTexasBirdGuide.gistId.v1`); token in `sessionStorage` only.
- **Category restructure:** 8 groups — Songbirds, Birds of Prey, Waterbird, Shorebird, Duck, Goose, Gull, Other.
- **Category color coding:** `src/utils/typeColors.js` is the canonical map; used by BirdCard and SightingCalendar.
- **Abundance scale:** 6-point scale: Most Rare → More Rare → Rare → Common → More Common → Most Common.
- **Widescreen layout:** Grid scales 1→2→3→4→5 columns. All containers use `max-w-screen-2xl`.
- **Security/dedup:** `mergeSightings`, `getLocalDateKey`, `matchesFilter` extracted to utils; 22 vitest unit tests.

The app includes:
- **109 species** with full data records and embedded photos
- **Frequent Flier tag** — `frequentFlier: true` on curated species; amber "✈ Frequent Flier" badge; filterable
- **Sighting tracker** — "seen today" toggle per card; state persists in `localStorage`
- **SightingCalendar** — collapsible month grid with daily sighting counts and selected-day species list
- **Backup/Restore** — JSON export/import; stale-backup warning after 14 days
- **GitHub Gist Sync** — optional auto-sync via `useGitHubSync`; PAT in `sessionStorage` only

## Decisions
- Season displayed in card image overlay; not a filter tab
- Category colors defined once in `src/utils/typeColors.js` — do not duplicate
- `frequentFlier: true` set manually per species in `birds.js`
- Sighting history is local-only in `localStorage`; GitHub Gist sync is opt-in
- PAT stored in `sessionStorage` — clears on tab close by design; Gist ID in `localStorage`
- No new runtime dependencies; date handling uses native JS; GitHub sync uses native `fetch`
- Sightings collapsed state is not persisted — calendar opens expanded on page load
- OneDrive target is `/mnt/c/Users/alexa/OneDrive/north-texas-bird-guide.html` (personal OneDrive, WSL path)
- App is distributed as a self-contained HTML file — no app store publishing planned

## Commands
```bash
npm run dev              # dev server (add -- --host 0.0.0.0 for LAN/Android)
npm run build            # production single-file build → dist/index.html + copy to OneDrive
npm run embed-images     # regenerate src/imageData.js from src/images/
npm run build:full       # embed-images + build (+ OneDrive copy)
npm run build:android    # embed-images + build + cap sync android
npm test                 # vitest unit tests (22 tests)
```
