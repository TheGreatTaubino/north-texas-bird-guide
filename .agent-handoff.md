# Agent Handoff

## Goal
Continue the North Texas Bird Field Guide React/Vite project. The core feature set is complete. Future work is incremental — new species, photo improvements, UX tweaks, or sync enhancements.

## Current State
`master` is up to date. Working tree is clean.

### Recent Changes
- **Gist ID persistence:** Gist ID now stored in `localStorage` (`northTexasBirdGuide.gistId.v1`); token remains in `sessionStorage` only. Connect form pre-fills Gist ID on new sessions — reconnect only requires pasting the token. Disconnect clears the token but keeps the Gist ID.
- **Frequent Flier:** European Starling and Rock Pigeon added to the Frequent Fliers list.
- **Category restructure:** Bird types reorganized into 8 groups — Songbirds, Birds of Prey, Waterbird, Shorebird, Duck, Goose, Gull, Other. Woodpeckers moved to Other; Raptors and Owls merged into Birds of Prey.
- **Category color coding:** Each type has a canonical color in `src/utils/typeColors.js`. Badges on BirdCard and the type tag in SightingCalendar both use this shared map.
- **Abundance scale:** Badge abundance terms standardized to a 6-point scale: Most Rare → More Rare → Rare → Common → More Common → Most Common. Seasonal qualifiers stripped from abundance badges (season still shown in card overlay).
- **Filter bar:** Season filters (Year-Round, Summer, Winter) removed. Type filters updated to match new categories.
- **Widescreen layout:** Grid scales 1→2→3→4→5 columns across breakpoints. All containers widened from `max-w-5xl` to `max-w-screen-2xl`.
- **Central Flyway banner removed** from main view.
- **Security/dedup (prior session):** `importSightings` delegates to `mergeSightings` in `src/utils/sightings.js`; `getLocalDateKey` extracted to `src/utils/dates.js`; `matchesFilter` extracted to `src/utils/filter.js`; 22 vitest unit tests.

The app includes:
- **109 species** with full data records and embedded photos
- **Frequent Flier tag** — `frequentFlier: true` on curated species; amber "✈ Frequent Flier" badge; filterable in filter bar
- **Sighting tracker** — "seen today" toggle per card; state persists in `localStorage`
- **SightingCalendar** — month grid with daily sighting counts and selected-day species list (type tags use category colors)
- **Backup/Restore** — JSON export/import; stale-backup warning after 14 days
- **GitHub Gist Sync** — optional auto-sync via `useGitHubSync`; PAT in `sessionStorage` only

## Decisions
- Season is displayed in the card image overlay (`Type · Season`) but not as a filter tab
- Category colors are defined once in `src/utils/typeColors.js` and imported wherever needed — do not duplicate
- `frequentFlier: true` is set manually per species in `birds.js`
- Sighting history is local-only in `localStorage`; GitHub Gist sync is opt-in
- PAT stored in `sessionStorage` — clears on tab close by design; Gist ID stored in `localStorage` (not sensitive)
- No new runtime dependencies; date handling uses native JS; GitHub sync uses native `fetch`
