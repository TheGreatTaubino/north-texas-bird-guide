# Agent Handoff

## Goal
Continue the North Texas Bird Field Guide React/Vite project, preserving the current in-progress expansion of species data, card details, and section navigation.

## Current State
The repo is on `master` tracking `origin/master`. Recent commits completed a 97-species offline guide with embedded photos. The working tree has uncommitted edits in `src/App.jsx`, `src/components/BirdCard.jsx`, `src/data/birds.js`, `.gitignore`, and this handoff file. Current source changes add collapsible bird-type sections, display optional bird measurements on cards, and substantially rewrite/reorder `BIRDS` plus `TRIVIA` data with many `size`, `weight`, and `wingspan` fields. `npm run build` passed after these changes.

## Important Files
- `src/App.jsx` - Main app shell, filters, grouping order/labels, collapsible section state and UI.
- `src/components/BirdCard.jsx` - Bird card rendering, quick ID expansion, current measurement display.
- `src/data/birds.js` - Primary species and trivia dataset; currently the largest modified file.
- `src/imageData.js` - Embedded image data imported by the app; likely regenerated by `npm run embed-images`.
- `scripts/embed-images.js` - Converts `src/images/*.jpg` into embedded data for offline builds.
- `package.json` - Vite scripts: `dev`, `build`, `embed-images`, and `build:full`.
- `src/images/` - Bird photo assets; many untracked `*:Zone.Identifier` files are present and should probably not be committed.
- `.gitignore` - Now ignores both `*.Zone.Identifier` and `*:Zone.Identifier` metadata sidecars.

## Decisions
- Keep the project as a React 18 + Vite + Tailwind single-page/offline guide.
- Optional measurement fields are rendered only when present on a bird record.
- Section collapse state is local UI state using a `Set` keyed by bird type.
- `GROUP_ORDER` and `GROUP_LABELS` now include `Duck`, `Goose`, and `Gull`.
- Avoid committing Windows `Zone.Identifier` alternate-stream sidecar files unless there is a specific reason.

## Open Questions
- Whether the large `src/data/birds.js` rewrite is intentional and complete.
- Whether all image keys in the rewritten bird data still match entries in `src/imageData.js`.
- Whether the measurement icons/emojis are acceptable for the UI style and accessibility.
- Whether `Zone.Identifier` sidecar files should be deleted and/or ignored.
