# North Texas Bird Guide — Claude Context

## Project Purpose
Mobile-friendly React field guide for birds in Plano / DFW / Collin County. Designed for offline use. Deployed as a single self-contained HTML file (~16MB with embedded images) and as a Capacitor Android app named **NTX Birds**.

## Commands
```bash
npm run dev          # dev server at localhost:5173
npm run build        # production build → dist/index.html
npm run embed-images # regenerate src/imageData.js from src/images/
npm run build:full   # embed-images + build (use this when photos changed)
npm run preview      # preview production build locally
npm run cap:sync     # build web app and sync Capacitor Android
npm run android:build # build Android debug APK
npm run android:open # open Android project in Android Studio
```

On the Windows machine used for this project, global `node`/`npm` may not be on PATH. If needed, use the ignored portable Node checkout:

```powershell
.\.local-node\node-v24.14.0-win-x64\npm.cmd run win:cap:sync
.\.local-node\node-v24.14.0-win-x64\npm.cmd run win:android:build
```

Android builds require Android Studio/JDK and SDK paths. In PowerShell:

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
$env:ANDROID_HOME="$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_SDK_ROOT="$env:LOCALAPPDATA\Android\Sdk"
```

## Critical Build Constraints
- **Output is a single HTML file** via `vite-plugin-singlefile`. All assets must be inlineable.
- Do not introduce lazy imports (`React.lazy`, dynamic `import()`), async chunk splitting, or any pattern that produces multiple output chunks.
- Vite 8 / Rolldown: config uses `rolldownOptions` (not `rollupOptions`). `inlineDynamicImports: true` emits a deprecation warning — this is harmless; `vite-plugin-singlefile` controls code splitting via `codeSplitting: false` internally.
- `assetsInlineLimit` is set to 100MB so large images inline without being written to disk.
- Capacitor copied web assets under `android/app/src/main/assets/` are generated by `cap sync` and intentionally ignored.
- Debug APK output is `android/app/build/outputs/apk/debug/app-debug.apk`.

## Species Data Model (`src/data/birds.js`)
Each record in `BIRDS`:
```js
{
  id,          // unique string, no spaces (e.g. "americancrow")
  name,        // common name
  latin,       // scientific name
  type,        // group label (e.g. "Songbirds", "Raptors")
  subtype,     // optional finer grouping
  season,      // "year-round" | "summer" | "winter" | "migrant"
  color,       // Tailwind color class used for card accent
  imageKey,    // must match a key in src/imageData.js and filename in src/images/
  size,        // optional
  weight,      // optional
  wingspan,    // optional
  id_marks,    // field identification notes
  flight_id,   // in-flight ID notes
  northTexas,  // local DFW/Plano/Collin County context
  funFact,     // trivia blurb
  badges,      // array of badge strings shown on card
}
```
To add a species: add record to `BIRDS`, add photo to `src/images/`, then run `npm run embed-images`.

When adding new species, always provide a table of birds with missing images, the expected file name, and a link to the bird on https://merlin.allaboutbirds.org/

## Storage
| Key | Storage | Contents |
|-----|---------|----------|
| `northTexasBirdGuide.sightings.v1` | `localStorage` | Sighting history (date → species array) |
| `northTexasBirdGuide.lastExport.v1` | `localStorage` | Timestamp of last backup export |
| `northTexasBirdGuide.gistId.v1` | `localStorage` | Gist ID — persists across sessions (not sensitive; visible in gist URL) |
| `northTexasBirdGuide.syncConfig.v1` | `sessionStorage` in browser | GitHub token + last sync time — **clears on tab close** |
| `northTexasBirdGuide.githubToken.v1` | Android secure storage | GitHub token in native app, backed by AndroidKeyStore through `capacitor-secure-storage-plugin` |
| `northTexasBirdGuide.lastSyncedAt.v1` | `localStorage` | Last sync timestamp for native credential flow |

In browser builds, the GitHub PAT lives in `sessionStorage` intentionally — it clears when the tab or browser closes to limit token exposure. Do not move the browser token to `localStorage`. In the Android app, the PAT is persisted in native secure storage so users do not re-enter it on every launch. The Gist ID is stored separately in `localStorage` so the connect form can pre-fill it on reconnect.

## GitHub Sync
`useGitHubSync.js` pushes/pulls sighting data to a private GitHub Gist. Token requires only `gist` scope. `src/utils/syncCredentials.js` chooses native secure storage on Android and session-only storage in browser builds.

## Android App
The Android app label is `NTX Birds`, with package ID `com.northtexasbirdguide.app`. Launcher artwork is generated from `assets/android/ntx-birds-icon-source.png`; the generator pads the art to 72% of the canvas to avoid Android launcher masks cropping the bird/binoculars.

To regenerate icons:

```bash
python scripts/generate-android-icons.py assets/android/ntx-birds-icon-source.png
```
